Add a terminal dashboard for Linux, macOS and Windows. `quotaline-tui` collects quota itself, without a desktop app, and
shows grouped quota windows, history, settings and logs. Press `s` to sign in to a provider through its own command-line
tool. Each release ships a signed and notarized universal binary for macOS, and x86_64 builds for Linux and Windows. Run
`quotaline-tui --demo` to try sample readings.
